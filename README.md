## 👋 About me

I'm an MSc student in **AI for Business Intelligence** at the University of Leicester. I build machine learning and NLP projects that turn raw data into something a decision-maker can act on, and I like taking them end to end: preparing the data, training the model, then wrapping it in a simple interface anyone can use.
